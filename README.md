# NontonYUK 🎬

A movie streaming website concept built as my first HTML, CSS, and JavaScript project.

## Features
- Responsive dark-themed layout
- Movie cards with year, genre, and rating
- Featured titles section
- Login page
- Search bar

## Pages
- `Index.html` – Home page
- `LOGIN.html` – Login page
- Movie pages: Avengers Endgame, Toy Story 4, NOBODY, Pengabdi Setan 2

## Built With
- HTML
- CSS
- JavaScript
